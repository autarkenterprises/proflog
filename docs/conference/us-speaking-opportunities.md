## Outreach checklist

### Lead time

- Weekly seminars: often **1–3 months** ahead.
- Department colloquia: often **3–6 months** ahead.
- NYC CTS and Topos can fill faster because of popular virtual slots.

### Pitch email template

```
Subject: Seminar talk proposal — [short title]

Dear [Organizer],

I would like to propose a talk for [series name] on:

  Title: …
  Abstract (150 words): …

The talk covers [Proflog / SJAS / correspondence / core.logic angle] and
would suit [in-person / hybrid / virtual] delivery.

Preferred dates: …, …, …

[Bio one line + link to proflog repo or paper]

Best,
[Name]
```

### Reuse from IULS

The [iuls2026/](../../iuls2026/) deck forks cleanly:

- **50-min colloquium** — full SJAS + Proflog narrative.
- **20-min NJPLS/NEPLS** — kernel demo + one correspondence headline.
- **NYC CTS / Topos** — categorical or coalgebra framing of tableau / proof objects.

### Travel funding

- **MAMLS** (via NYLogic) and **Logic@TXST** explicitly fund visitor travel—mention if cost is a factor.
