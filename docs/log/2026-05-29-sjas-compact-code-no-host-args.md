# SJAS Compact Code Without Host Argument Projection

Date: 2026-05-29
Branch: `adr-0073-sjas-correspondence-program`

## Track 1 Slice

This Track 1 code-format slice removes the host helper that projected a ground
compact public `code-N` term to its Clojure argument list before byte decoding.

The previous path was better than a byte-value lookup because each byte still
passed through `code-byte-termo`, but it still used a host-side
`ground-compact-code-args` / `ground-code-argso` split to avoid walking large
ground terms. The new empty-substitution compact path unifies the public term
with the object shape:

```text
app(code-N, b0, ..., bN-1)
```

and then consumes the byte argument list with the same recursive `code-argso`
relation used by the general code reader. There is no host projection of the
argument list.

## Large Semantic Boundary

Removing the host argument projection initially exposed a real runtime cost.
The focused selector `sjas-tableau-proof-accepts-axiom-citation-certificates`
exceeded a 260s envelope because `code-constructoro` could enumerate the full
declared `code-N` signature after the constructor was bound through relation
unification rather than host destructuring.

That boundary is addressed in the same slice. Ground compact constructors now
commit to their structural arity after the root is bound; byte arguments still
flow through `code-byte-termo` / `code-argso`. The byte relation also regained
the generation direction needed for embedded `code(...)` terms by generating
canonical U-Grounding byte numerals from object byte values while preserving
the arithmetic parser for noncanonical ground byte terms.

The larger semantic tests exposed two more proof-output boundaries:

- direct host-AST proof-check targets need a signature-isomorphism bridge from
  host relation names to the reflected numeric relation index;
- large Group-3 theorem-code checks can succeed object-level while full proof
  reification is too expensive, so only large non-axiom tableau-proof reports
  use a compact proof summary after the SJAS close relation has succeeded.

The negative false-citation case exposed a separate large semantic boundary.
When a `tableau-proof(system, false, sjas-axiom)` citation failed to find
`false` among the beta axioms, the tableau checker could fall through to the
non-axiom proof-tree branch and attempt to interpret `sjas-axiom` as a full
certificate. The branch split now commits on the decoded `sjas-axiom` marker
before axiom membership is checked, so absent axiom citations fail there.
The beta scan also uses a structural non-reifying byte skipper for encoded
formula records, preserving an object-level system-code traversal without
constructing a complete decoded formula tree for every nonmatching beta axiom.

The standalone bounded Level-1 contradiction probe is still kept focused:
because that diagnostic supplies the `sjas-axiom` certificate for `false`, it
checks the already-built finite system records before launching proof search.
That optimization is outside the proof predicate path.
