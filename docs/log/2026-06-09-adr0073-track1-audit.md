# ADR-0073 Track 1 Audit

## Scope

This audit tracks only ADR-0073 Track 1: direct arithmeticization of the SJAS
proof predicate. It does not start Track 2 correspondence work and does not
treat SelfCons runtime as an optimization target.

## Current Evidence Map

ADR-0073 organizes Track 1 into eight implementation slices:

1. **Code format:** compact byte terms and U-Grounding numeral codes are
   inspectable public code terms. Evidence includes trailing-zero preservation,
   U-Grounding code-format tests, and source audits rejecting host code
   projectors. ADR-0083 closed the public compact reader gap by requiring
   `code-argso` and `code-args-coreo` to parse presented byte numerals through
   `code-byte-termo`, while preserving byte-first reconstruction only for
   embedded payloads.
2. **Syntax:** `wff`, formula-class, and `neg-pair` predicates decode encoded
   formulas through object relations. Evidence includes compact and U-Grounding
   syntax predicate tests with code-reader proof evidence.
3. **System-code reconstruction:** `axiom-member/2`, fixed axiom groups,
   beta formulas, Group-3, and reflected clauses are recovered from
   `system-code`, with generated fact registries rejected by tests. ADR-0084
   additionally requires `tableau-proof/3` and `subst-prf/4` structural
   branches to read `system-code` through branch equality state before
   reconstructing `AxiomConj`.
4. **Proof-code grammar:** formula-bearing proof nodes, wide proof nodes, byte
   payload evidence, U-Grounding canonical-byte evidence, and legacy proof-rule
   rejection are covered by proof-code encoder/decoder tests.
5. **U-Grounding arithmetic:** byte/numeral interpretation and fixed-radix
   byte-cons evidence are exercised by syntax, proof, and substitution
   selectors.
6. **Substitution and fixed points:** `subst-code/2`, `subst-prf/4`, Level-1
   skeleton substitution, and explicit substituted-source antecedent tests
   cover the current implementation.
7. **Tableau proof checking:** formula-bearing structural proof tests cover
   alpha/beta rules, quantifiers, bounded quantifiers, equality, disequality,
   arithmetic closure, saved literal closure, recursive proof-predicate leaves,
   and proof-rule tag exclusion.
8. **Reflected procedure calls:** positive, negative, alternative, guarded, and
   equality-triggered reflected call tests recover clauses from encoded
   `system-code`, not host runtime clause tables.

The proof-facing shortcut audits also now reject:

- generated theorem/proof registries;
- host byte projectors;
- direct host-ground proof entrypoints;
- `kernel/prove-programo` inside proof-predicate validation;
- committed-choice `conda` in proof-facing paths;
- optional nil dispatch for generic kernel proof hooks.
